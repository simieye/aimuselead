# tuoquan-ai · 拓圈AI复刻（全球鹰外贸AI获客体系版）

AI 创业者线下沙龙 + 付费人脉圈 H5 应用（复刻自拓圈类产品形态，内容以全球鹰外贸AI获客体系 V1.5 为底座）。

- 线上地址：https://tuoquan-ai.vercel.app
- 形态：单文件静态 H5（index.html），手机窄栏布局，数据保存在浏览器 localStorage
- 功能：沙龙列表/详情与报名、年度老板会员（¥1980/年）、老板圈子动态、老板资源库（管理员可添加名录）、分销中心（邀请码/佣金/提现申请）、管理后台（活动/订单/会员/名录/引荐/提现/设置）、全球鹰体系页（九大 SOP / 双赛道 / 三维流量矩阵 / 买手视角 / AI 智能接待 / 风控底座）
- 支付：微信商户收款码扫码支付（静态码，订单状态「已支付(待核对)」，商家核对微信收款记录后确认）

## 脱敏说明（本仓库为脱敏存档版）

- 真实微信收款码图片（pay-merchant-s.png / pay-tim-s.png）**不在本仓库**：涉及真实收款账户，仅在部署时注入，仓库内 index.html 保留同名引用。
- 演示账号密码已替换为占位符 `__DEMO_ADMIN_PASSWORD__` / `__DEMO_MEMBER_PASSWORD__`，真实部署副本中为演示口令；「一键体验」入口不依赖密码。
- 代码中无 API 密钥、令牌、真实手机号或邮箱。

## 部署

静态文件直接部署到 Vercel（根目录即站点根）。如需从本仓库做 Git 部署，请先把两张收款码图片放回根目录同名文件，否则支付弹层图片会 404。
